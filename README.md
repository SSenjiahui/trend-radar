# 🌟 全网热点雷达 · TrendRadar

> **实时聚合各大社交平台热搜、讨论量与点击量的现代化排行榜系统**

---

## ✨ 核心特性

- ⚡ **多平台实时聚合**：
  - **微博热搜**（实时热搜榜、热度值、爆/热/新/沸/荐状态标签）
  - **知乎热榜**（热度指数、讨论回答数、深度摘要）
  - **抖音热点**（短视频实时热度、互动指数）
  - **哔哩哔哩**（全站热门视频、播放量、弹幕数）
  - **百度热搜**（实时搜索指数、热度增长）
  - **今日头条**（全网资讯热点）
  - **掘金技术 & GitHub Trending**（科技开发者与开源趋势）
- 🔮 **全网超级热度算法**：跨平台重合度加权算法，自动挖掘同时登上多个平台的超级热点。
- ⏱️ **实时无缝更新**：支持 **15s / 30s / 60s** 自动倒计时刷新、一键手动刷新与 SSE 实时数据流推送。
- 🔍 **全局即时搜索与分类筛选**：支持按关键词跨平台秒级检索，按综合、科技、娱乐、生活、财经等分类筛选。
- 🎨 **双重视图切换**：
  - **多列并排矩阵视图 (Grid)**：一览全网各大平台动态。
  - **单平台聚焦视图 (Tabs)**：深度浏览单一平台的完整数据。
- 📌 **本地收藏夹**：一键保存感兴趣的话题，离线追踪。
- 🌙 **现代暗黑/明亮主题**：科技感 Glassmorphism 毛玻璃设计与细腻流畅的动画。

## 🚀 快速启动

### 方式一：一键启动完整应用（推荐）

```bash
# 启动内置 Web & API 服务（已打包前端静态资源）
npm start
```
访问：**`http://localhost:3001`** 即可使用！

---

### 方式二：开发模式启动（热重载）

```bash
npm run dev
```
- 前端 Vite 界面：`http://localhost:5173`
- 后端 API 服务：`http://localhost:3001`

---

## 🛠️ 技术架构

- **后端**：Node.js + Express + Axios + Cheerio + 内存 TTL 缓存与并发限流保护
- **前端**：React 18 + Vite + Tailwind CSS + Lucide Icons
- **实时传输**：Server-Sent Events (SSE) + 智能倒计时轮询
